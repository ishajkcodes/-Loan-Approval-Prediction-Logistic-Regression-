
# Loan Prediction Model (Logistic Regression)

## 📌 Overview
This project addresses one of the most critical challenges in the banking and financial sector: evaluating loan applications efficiently and accurately.  
Traditional manual processes are slow, inconsistent, and prone to human bias.  

By applying **Logistic Regression**, this project builds a binary classification model to predict loan approval outcomes.

## 🎯 Project Objective
The goal is to train a model using applicant features such as:
- Annual Income  
- Credit Score  
- Total Assets  
- Loan Amount  
- Employment Information  

The model supports faster, fairer, and data-driven lending decisions.

## 💡 Business Impact
- Identify low-risk applicants for approval  
- Flag high-risk applicants for review  
- Reduce manual processing time  
- Minimize human error  
- Ensure consistent decision criteria  

## ⚙️ Technologies Used
- Python  
- Pandas & NumPy (data preprocessing)  
- Matplotlib & Seaborn (EDA & visualization)  
- Scikit-learn (logistic regression model)  

## 📊 Exploratory Data Analysis
Some of the relationships explored include:
- Annual income vs loan amount  
- Impact of dependents on loan approval  
- Effect of credit score (CIBIL) on approval  
- Loan term distribution and approval rates  
- Self-employment status and its influence
